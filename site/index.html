Choose your platform

Bring your game.
Yakumo handles the rest.

Download a prebuilt release, start Yakumo, and select the disc image from your own legally obtained copy. The guided setup verifies and prepares it locally.

No game data is included. Yakumo is the software, not the game.
01

Windows

x86-64
  1. Download the Windows ZIP from the latest stable release.
  2. Extract the complete folder and run Yakumo.exe.
  3. Choose your disc image in the first-run setup.

Normal and portable packages keep your data exactly where you expect it.

02

Linux & Steam Deck

x86-64
  1. Download the Flatpak bundle or portable tarball.
  2. Install it and start Yakumo once in Desktop Mode.
  3. Add Yakumo to Steam for the best Game Mode experience.

Native Vulkan and the Deck's built-in controls are supported.

03

macOS

Apple Silicon
  1. Download the macOS disk image.
  2. Drag Yakumo into Applications.
  3. Allow the unsigned app once, then complete setup.

Requires macOS 13 or newer and uses Vulkan through MoltenVK.

04

Android

arm64
  1. Download the arm64 APK and allow its installation.
  2. Pick your disc image through Android's file picker.
  3. Play with touch controls or a connected gamepad.

Requires Android 10 or later, a 64-bit device and Vulkan 1.1.

Under the hood

Native by design.

Yakumo is built around static recompilation. It is neither a traditional emulator nor a decompilation: the original machine code becomes C++, while a purpose-built runtime supplies the PSP services the game expects.

01

Analyze and translate

Yakumo analyzes the game's PSP machine code and translates it into portable C++ ahead of time.

02

Compile natively

The translated code is compiled for the host machine as a native executable and libraries.

03

Supply the PSP system

Yakumo provides the kernel, renderer, audio, input, saves and networking around the game.
